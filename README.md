## Descripción del programa
Programa de consola en C# que registra 3 productos de la tienda TecnoPunto.
Usa la clase `Producto` con propiedades que validan los datos y calcula el valor total en existencia.

## Datos de entrada
Código, nombre, precio y cantidad de cada producto (por teclado).

## Datos que procesa
- Valida que el nombre no esté vacío, el precio sea mayor que 0 y la cantidad no sea negativa.
- Calcula el valor total: precio × cantidad.

## Datos de salida
Información del producto (código, nombre, precio, cantidad y valor total) o un mensaje de error si algún dato es inválido.
